# Registrations

Ce sous-domaine gère les inscriptions, leur horodatage, leur statut et leur annulation avant la date limite. Il vérifie l'adhésion active, le niveau d'habileté et les places disponibles. Lorsque la randonnée est complète, il conserve la liste d'attente dans l'ordre d'inscription et promeut le premier randonneur lorsqu'une place se libère. Les courriels relèvent de notifications.
