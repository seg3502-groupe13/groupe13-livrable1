# Trails

Ce sous-domaine concerne les informations sur les sentiers publiées par la CCN, notamment la difficulté, la saison d'ouverture, les activités permises et le point de départ. Ces informations servent à choisir les sentiers admissibles et à planifier les randonnées. Le club ne crée ni ne modifie les sentiers; il utilise les données de la CCN.
